# HTTP vs HTTPS Comparison

A short comparison document explaining the difference between HTTP and HTTPS, and why HTTPS is essential for modern websites.

## Contents

* `http-vs-https-comparison.docx` : Word version



## Key Differences

|Point|HTTP|HTTPS|
|-|-|-|
|**Encryption**|Plain text|Encrypted with TLS|
|**Port**|80|443|
|**Certificate**|Not needed|SSL/TLS certificate required|
|**Data integrity**|Can be altered in transit|Tampering is detected|
|**Browser / SEO**|"Not secure" warning, lower ranking|Padlock, ranking benefit|
|**Performance**|HTTP/1.1|HTTP/2 and HTTP/3|

## Why HTTPS is a must

Login details, payments and personal data must not be stolen or changed in transit. HTTPS builds user trust and avoids browser security warnings.
